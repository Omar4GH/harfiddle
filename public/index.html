To read HTTPS, HarFiddle answers each connection with its own certificate for that site (TLS interception), signed by a root certificate created on this Mac. Clients only accept that if they trust the root certificate.

        
So that system capture never breaks your internet, traffic from the system proxy is decrypted only on port 443, only while macOS trusts the root certificate, and never for hosts whose app rejected the certificate (those are tunneled for 30 minutes; see Log). Browse windows and clients you point at the proxy yourself are always decrypted.

*404, *500 …           that status, empty body
*delay:2000            wait, then send to the real server
*drop  /  *reset       close / reset the connection
*redir:https://…       307 redirect
http://localhost:3000  send to another server (REGEX $1, $2 … allowed)
